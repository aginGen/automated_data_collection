# Устойчивость в n8n

Три запроса по десять записей, Wait 0,6 секунды, расписание и ручной запуск.
HTTP Request возвращает статус, не превращая 4xx в повторяемую ошибку. Code классифицирует 429/5xx и ограничивает попытки. Retry On Fail отвечает за сетевые ошибки. При 404 — один запрос, журнал и Stop and Error.
Получены 30 строк. Подтверждены четыре запроса в 429-сценарии и один при 404.
Token bucket, полноценный circuit breaker, условный кэш и распределённый лимит здесь не реализованы. Небольшой сценарий может запускаться ежедневно: 30 запусков и 90 запросов за 30 дней без сбоев. Плата локальной установке и API — 0, оборудование не оценивалось.
