| Условия использования | Тренировочные источники; для Open Library учтены правила API. A выполняется только локально. |
| robots.txt | Quotes: 404, запрета нет. Open Library: файл получен, Disallow: /search охватывает Search URL, can_fetch=false, запрос пропущен. Crawl-delay/request_rate для нашего UA не заданы; Sitemap сохранён. Правила — reports/robots_openlibrary.txt. |

| Состав данных | Книги, цитаты и имена авторов. Контакты и адреса не собираются. Имена могут быть ПД. |
| Основание | Для учебной научной деятельности рассмотрен п. 8 ч. 1 ст. 6 152-ФЗ с соблюдением прав. |
| Хранение и удаление | Локальные файлы и учебный репозиторий; до 30 дней после проверки, с учётом кэшей и версионных копий. |
| Контакт | User-Agent содержит ссылку на репозиторий aginGen/automated_data_collection. |
| При блокировке | Остановка домена, артефакт и красный статус; другой источник продолжает работу. |
