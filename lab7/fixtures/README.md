# Учебные ответы

Снимки 30 цитат из ранее выполненного HTML-сбора и 30 книг из Open Library. HTML пересобран из сохранённых полей, JSON приведён к форме records. Это локальная учебная площадка, а не новые ответы внешних серверов. Сервер добавляет управляемые 500, 404, 429, заглушку 200 и HTTP-кэширование.
