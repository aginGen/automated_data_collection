# Лабораторная 4. Динамические страницы: Playwright и n8n

ПМИ-2-2025. Вариант 3 — `scrapingcourse.com/infinite-scrolling`.

Playwright, HTTP-XHR и n8n получили один и тот же полный каталог: **147 уникальных товаров**. Совпадают ключи, названия, цены, валюты, ссылки и порядок строк. Время наблюдения у способов различается. На площадке меньше 200 товаров; ограничение объёма явно описано в [отчёте](report.md) по предоставленному примеру ЛР4.

## Установка

Нужен Python 3.10+. Команды выполняются из папки лабораторной. Окружение размещается в соседнем техническом каталоге:

```powershell
python -m venv ..\.lab-runtime\lab4-python
..\.lab-runtime\lab4-python\Scripts\python.exe -m pip install -r requirements.txt
..\.lab-runtime\lab4-python\Scripts\python.exe -m playwright install chromium
```

Откройте ноутбук в VS Code / Jupyter, выберите это окружение и выполните ячейки сверху вниз. По умолчанию показываются сохранённые результаты и выполняются проверки CSV. Обращения к сайту отключены. Метрики, параметры измерений и результаты автономных проверок хранятся внутри самого ноутбука.

## Повтор сбора и проверок

В ячейке **«Локальный rendering API и запуск»** находятся флаги:

| Флаг | Действие |
|---|---|
| `RUN_COLLECTION = True` | Повторить диагностику, браузерный сбор, HTTP-сбор, сверку и замер блокировки медиа |
| `RUN_RESILIENCE_CHECKS = True` | Выполнить автономные проверки предохранителей, редизайна и smoke-check |
| `RUN_N8N = True` | Выполнить полный workflow n8n и проверить совпадение с обоими основными CSV |
| `RUN_N8N_ERROR_CHECK = True` | Проверить ветку ошибки rendering API |
| `START_N8N_EDITOR = True` | Запустить локальные rendering API и редактор n8n |
| `STOP_SERVICES = True` | Завершить сервисы, запущенные этим ноутбуком |

После изменения нужного флага выполните эту ячейку повторно. Для следующего обычного просмотра верните флаги в `False`. Новый браузерный и HTTP-срез, дополнительные журналы и измерения появятся во временной папке, путь которой напечатает ноутбук. Сохранённые основные CSV при таком сборе не перезаписываются. Полный запуск n8n сохраняет результат в `nocode/nocode_result.csv`; его технические журналы находятся во временной папке.

Браузер выполняет максимум 24 прокрутки, останавливается после двух итераций без новых ключей или при достижении лимита 200 товаров. Пауза между взаимодействиями — не меньше 1 с. Ответы данных ожидаются через `expect_response` и `wait_for_function`. Порции перекрываются: при шаге offset=10 сервер возвращает до 12 карточек. Поэтому в конце DOM содержит 187 карточек, а CSV — 147 уникальных товаров.

Для отдельной демонстрации таймаута после вызова `work = prepare_runtime()` можно выполнить в ячейке:

```python
result = subprocess.run(
    [sys.executable, "-X", "utf8", str(work / "collect.py"), "demo-timeout",
     "--out", str(work / "timeout-demo")],
    cwd=LAB_ROOT,
)
assert result.returncode == 2
```

Код 0 означает успех, 1 — фатальную ошибку, 2 — специально вызванный таймаут. Исходники всех временных скриптов находятся в ячейках ноутбука. Запускайте сетевые сценарии последовательно. При изменении каталога обновляйте и сверяйте все три набора.

## n8n

Для n8n требуется Node.js 22. Установите зафиксированную версию в соседний технический каталог:

```powershell
npm.cmd install --prefix ..\.lab-runtime n8n@1.121.3 --no-audit --no-fund
```

Выполните начальные ячейки ноутбука, затем установите `RUN_N8N = True` в ячейке запуска. Ноутбук запустит локальный rendering API, импортирует [workflow.json](nocode/workflow.json), выполнит сценарий и остановит сервис после завершения. Rendering API действительно исполняет JavaScript и прокручивает учебную страницу; n8n получает DOM по HTTP и самостоятельно извлекает карточки узлами HTML. Результат — [nocode_result.csv](nocode/nocode_result.csv).

Для просмотра схемы и ручного запуска установите `RUN_N8N = False`, `START_N8N_EDITOR = True` и выполните ячейку. Откройте `http://127.0.0.1:5684`, при первом запуске создайте локального пользователя, выберите **Lab 4 variant 3 JS scroll** и нажмите **Execute workflow**. После работы выключите этот флаг и выполните ячейку с `STOP_SERVICES = True`.

При ручном импорте JSON укажите абсолютный путь `nocode/nocode_result.csv` в узле **Save CSV**, а для **Save error CSV** выберите путь вне папки сдачи. Автоматический запуск из ноутбука подставляет эти пути сам. Rendering API слушает `127.0.0.1:8894` и принимает только учебный URL. Workflow неактивен; триггер настроен на 08:00 `Asia/Yekaterinburg`.

Ветка отказа записывает журнал и завершает workflow ошибкой. Для её проверки оставьте редактор n8n остановленным и включите `RUN_N8N_ERROR_CHECK`. Проверка должна подтвердить ожидаемую ошибку выполнения.
