# Переносимые схемы n8n: лабораторные 3–7

В комплекте находятся JSON схем в `workflows/`, локальные помощники ЛР4 и ЛР5 и входной срез ЛР6. Пути файлов в схемах относительны к корню этого комплекта; запускатель сам выбирает этот рабочий каталог. Требуются Python 3.10–3.12, Node.js 22 и доступ к интернету для установки и для работы с внешними источниками. Chromium нужен ЛР4. В ЛР3 перед поиском проверяется robots.txt; остальные схемы не дают общей автоматической гарантии соблюдения правил всех источников.

## Первый запуск

Откройте терминал в любом каталоге и перейдите в корень распакованного комплекта. В Windows используйте `python`, в Linux при необходимости замените его на `python3`:

```text
python launch.py --setup --browser
python launch.py --check
python launch.py --port 5679
```

Установка создаёт `.venv`, `node_modules` с n8n 1.121.3 и `.local/browsers` с Chromium; глобальная установка пакетов не используется. Для запуска без браузерного помощника можно установить `--setup` без `--browser`, а затем установить Chromium отдельным повторным вызовом `--setup --browser`. Либо запускайте `start.cmd`, `start.ps1` или `sh start.sh` с теми же аргументами. Загрузка Chromium и нужных системных библиотек зависит от ОС; на некоторых Linux может потребоваться отдельная установка системных зависимостей Playwright.

Откройте `http://127.0.0.1:5679`, создайте локальную учётную запись и импортируйте схемы `workflows/lab3.json` … `lab7.json` через редактор n8n. Импортируйте каждую отдельно. Новое расписание не включается автоматически: проверьте, что все схемы неактивны. При последующих запусках n8n может восстановить ранее вручную активированные схемы; перед переносом или запуском отключите их в старом профиле. Ручной запуск схемы может обращаться к интернету, а ветка уведомления — отправить сообщение; проверяйте настройки до запуска.

По умолчанию локальный браузерный API работает на `127.0.0.1:8894`, а локальные уведомления — на `127.0.0.1:5686`. Если порт занят другим процессом или копией комплекта, запускатель его не меняет и сообщает об этом. Для занятого порта n8n используйте, например, `python launch.py --port 5687`. Только для лабораторных без этих помощников допускается `--no-helpers`. Для остановки запущенных этим запускателем процессов нажмите Ctrl+C; уже существующие сервисы он не останавливает.

Результаты записываются в `outputs/lab3/` … `outputs/lab7/`: `nocode_result.csv`, `error_log.csv` и, для ЛР6, `rejects.csv`. Исходный снимок ЛР6 — `labs/lab6_3/nocode/input.json`. Доступ файловых узлов n8n ограничен каталогами `outputs` и `labs/lab6_3/nocode`; приватный профиль и зависимости в этот список не входят. Прокси не предполагается; если сеть требует прокси, задайте стандартные `HTTPS_PROXY` или `HTTP_PROXY`. Для localhost используется прямое соединение.

## Доступ к поиску ЛР3

Перед `Fetch books` схема получает robots.txt Open Library с тем же User-Agent и проверяет `/search.json` для подходящей группы правил. Запрет, сетевой сбой, ошибочный HTTP-ответ (кроме 404), некорректный файл или неразобранное ограничение частоты останавливают выполнение до поиска. При 404 схема считает правила отсутствующими; это само по себе не доказывает разрешение по условиям сайта. Правила с ограничениями Crawl-delay или Request-rate требуют ручной проверки и настройки скорости; запрет с параметрами запроса обрабатывается консервативно. Селектор проверки рассчитан именно на текущий `/search.json` и User-Agent: при изменении адреса или агента необходимо обновить проверку и сверить условия источника. Сохранённые результаты ЛР3 получены ранее; если сайт сейчас запрещает поиск, нового запроса не будет.

## Перенос и учётные данные

Копируйте исходный комплект, включая `workflows/`, `services/` и `labs/`. На новой машине повторите `--setup --browser`: `.venv`, `node_modules`, `.local` и `outputs` не входят в перенос и создаются заново. В `.local` находятся закрытые данные n8n; не публикуйте и не отправляйте эту папку, CSV с приватными данными или токены. Для Telegram создайте собственный credential и укажите свой Chat ID в n8n; готовых токенов комплект не содержит. Не включайте расписание и не отправляйте тестовые сообщения без необходимости.
