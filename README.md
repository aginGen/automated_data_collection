## Просмотр и запуск Python

Начните с README нужной лабораторной. Там указаны окружение, команды и выходные файлы. Зависимости и локальные проверки выполнены на Python 3.10. Переносимый комплект n8n рассчитан на Python 3.10–3.12 и Node.js 22.

Для установки зависимостей создавайте отдельное окружение в папке лабораторной. Просмотр сохранённых таблиц и локальный анализ не требуют обращения к источникам после установки пакетов. Первоначальная настройка Google Colab использует GitHub и PyPI.

Новые сетевые запуски могут получить другие данные. Для OpenWeather нужен собственный API-ключ в переменной окружения. Ключи и локальные учётные данные не входят в репозиторий.

На 31 октября 2026 года Open Library запрещает `/search` в `robots.txt`. В лабораторной 3 сохранён прежний учебный результат. Python и n8n проверяют актуальные правила перед новым запросом и останавливаются при запрете. Менять User-Agent для обхода этого ограничения не нужно.

## n8n для лабораторных 3–7

Комплект [n8n_portable](n8n_portable/README.md) находится в этом репозитории. Из его папки выполните:

```text
python launch.py --setup --browser
python launch.py --check
python launch.py --port 5679
```

Откройте `http://127.0.0.1:5679`, создайте локальную учётную запись и импортируйте нужный JSON из `workflows`. Все экспортированные расписания выключены. Относительные пути начинаются от папки комплекта, результаты появятся в `outputs/labN/`.

Запуск n8n сам по себе не запускает сбор. В лабораториях 4 и 5 используются локальные помощники, их поднимает launcher. Для Telegram в лабораторной 7 нужно отдельно настроить собственного бота и Chat ID.

## Границы результатов

В лабораторной 4 получен полный доступный каталог из 147 товаров при требовании 200. В лабораторной 5 получены 100 уникальных цитат при требовании 300. Эти ограничения раскрыты в отчётах, повторные появления записей не считаются новыми данными.
