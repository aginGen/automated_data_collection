# Цены учебного книжного каталога в рублях

aginGen · Итоговый проект по курсу «Автоматизированный сбор данных из интернета»

**Вопрос.** Как меняется доля книг разных категорий в бюджете 3 500 ₽ при изменении курса фунта?

**Конфигурация B.** Python собирает каталог и курсы, проверяет данные, загружает их в SQLite и пересчитывает цены. n8n запускает Python и показывает результат или ошибку.

Книги и цены берутся из [Books to Scrape](https://books.toscrape.com/), курсы — из [Курсов ЦБ РФ в XML и JSON, API](https://www.cbr-xml-daily.ru/). Для пересчёта нужны цена книги, валюта и дата действия курса. В сохранённом наборе 1 000 книг. Цены на сайте учебные.

## Запуск на Windows

Откройте PowerShell в папке проекта. Нужен Python 3.10 или новее.

~~~powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m src.run_pipeline --mode full
~~~

Полный обход занимает около двух минут при доступной сети. Для работы с сохранёнными данными выполните пересборку.

~~~powershell
.\.venv\Scripts\python.exe -m src.run_pipeline --mode rebuild
~~~

Пересборка читает `raw` и `state` без сети. `FINAL_CONTACT` позволяет задать другой HTTPS-адрес или `mailto:` для `User-Agent`. По умолчанию используется контакт из `config.yaml`. Ключи API не требуются.

В `raw` лежат исходные ответы, в `clean` — проверенные книги и курсы в Parquet, в `mart` — пересчитанный каталог и агрегаты. Отчёт о каждом запуске лежит в `reports`, подробный журнал — в `logs`.

Для анализа откройте `analysis.ipynb` в VS Code или Jupyter, выберите Python из `.venv` и выполните ячейки сверху вниз. Блокнот читает сохранённые результаты.
