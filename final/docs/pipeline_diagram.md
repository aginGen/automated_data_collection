# Схема проекта

~~~mermaid
flowchart LR
    B["Книги из HTML"] --> R["raw · ответы и метаданные"]
    F["Курсы GBP из JSON"] --> R
    R --> N["Очистка и контракт"]
    N --> Q{"Пороги качества"}
    Q -->|зелёный или жёлтый| C["clean · Parquet"]
    Q -->|красный| E["Отчёт · код 2"]
    C --> S["SQLite · UPSERT"]
    S --> M["mart · пересчёт и агрегаты"]
    N --> X["rejects · поле и причина"]
    T["n8n · расписание"] --> P["Запуск Python"]
    P --> B
    P --> F
    P --> L["Журнал · метрики · сообщение в n8n"]
~~~

Курс связывается с книгой по GBP и дате действия. Состояние хранит очередь страниц и позицию следующей проверки. Ответ дописывается в `raw` до обновления очереди. После прерывания обход продолжается с оставшихся страниц.
