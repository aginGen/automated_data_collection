# Паспорта источников

| Поле | HTML-каталог | REST API курсов |
|---|---|---|
| Источник | Books to Scrape | Курсы ЦБ РФ в XML и JSON, API |
| Точка входа | `GET https://books.toscrape.com/` | `GET https://www.cbr-xml-daily.ru/daily_json.js` |
| Ответ | HTML в UTF-8 | JSON в UTF-8, возможен gzip |
| Пагинация | Категории в навигации, затем ссылка `li.next a` до её исчезновения | Один документ. Для GBP используются `Date`, `PreviousDate` и поля `Valute.GBP` |
| Авторизация | Публичный каталог | Публичный JSON, ключ не нужен |
| Лимиты | Опубликованных числовых лимитов нет. Проект задаёт до 0,9 запроса/с | До 1 запроса/с, 30/мин и 10 000/сутки с IP. Проект задаёт до 0,4 запроса/с |
| Уникальность | Числовой ID позиции в ссылке на карточку, ключ `books:<id>` | Код валюты и дата действия курса, ключ `GBP:<date>` |
| Заголовки | `User-Agent`, `Accept-Encoding: gzip`, при повторе `If-None-Match` и `If-Modified-Since` | Те же заголовки при наличии валидаторов. У проверенного ответа был `Last-Modified` |
| Персональные данные | Поля карточек книг, без сведений об авторах и покупателях | Даты и котировки валют |

`reports/robots.json` содержит результаты проверок. Каталог вернул 404 для `robots.txt`. На главной странице сказано, что сайт создан для практики сбора. У сервиса курсов `robots.txt` доступен и не запрещает запрос к точке входа. Если сервер задаст `Crawl-delay` или `Request-rate`, проект применит более медленный предел.

## Проверка HTML

В исходном HTML главной страницы найдены 20 карточек и ссылки на 50 категорий. Там уже есть полное название первой книги и её цена. При загрузке страницы в Chromium журнал сети показал запросы документа и скриптов. В фильтре Fetch/XHR записей не было. Картинки, стили, шрифты и видео были отключены для этой проверки. Обход категорий работает через обычные `GET`, следующую страницу сборщик берёт из ссылки. Результаты обеих проверок сохранены в `reports/html_diagnostic.json`.

| Селектор | Поле |
|---|---|
| `.side_categories ul ul a[href]` | Ссылки категорий |
| `article.product_pod` | Блок книги |
| `h3 a[title]` | Полное название и ссылка с ID |
| `p.price_color` | Цена со знаком фунта |
| `p.star-rating`, `p.availability` | Рейтинг и наличие |
| `li.next a[href]` | Следующая страница категории |

Если карточки исчезнут или ссылка Next выйдет за границы категории, сборщик остановит этот домен и запишет ответ в `logs/incidents`.
