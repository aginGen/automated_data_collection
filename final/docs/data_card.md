# Паспорт данных

Учебный набор нужен для пересчёта стоимости книг в рубли. В сохранённом снимке 1 000 книг из 50 категорий и две даты курса. Одна строка книги соответствует карточке каталога. Одна строка курса соответствует GBP на дату действия.

Обновление запланировано ежедневно. Для основной таблицы берётся последний курс с датой действия не позже дня наблюдения по Москве. При появлении новых ответов прошлые котировки сохраняются.

| Поля | Происхождение и единицы |
|---|---|
| `business_key`, `source_id` | `books:<id>`. ID выделяется из пути в ссылке карточки. Ключ курса имеет вид `GBP:<date>` |
| `title`, `category` | Полное название из атрибута `title` и заголовок страницы категории. Лишние пробелы удалены |
| `currency`, `price_pence` | GBP и целое число пенсов из цены HTML |
| `rating`, `in_stock` | Оценка 1–5 из класса элемента и признак наличия. Неизвестное значение хранится как `null` |
| `product_url`, `source_url` | Ссылка карточки и адрес страницы, с которой она получена. У курса есть адрес JSON |
| `source`, `collected_at`, `parser_version` | Источник, время сбора исходного ответа в UTC и версия парсера |
| `updated_at` | Время вставки или изменения записи в SQLite. При неизменившихся значениях сохраняется |
| `rate_date`, `nominal`, `rub_x10000` | Дата действия курса, номинал 1 и рубли за фунт в единицах 0,0001 ₽ |
| `quote_field` | `Value` или `Previous` из ответа API |
| `price_rub_kopeks`, `price_rub`, `price_gbp` | Пересчёт в копейках и колонки для чтения в рублях и фунтах |
| `within_budget` | Цена после пересчёта не превышает 3 500 ₽ |
| `scenario`, `budget_share` | Вид расчёта и доля книг в бюджете внутри категории |

`raw/*.jsonl` сохраняет тело ответа, URL, статус HTTP, время UTC и контрольную сумму. Метрики полноты и причины брака записаны в `clean/quality.json` и отчётах о прогонах.

Цены и оценки в каталоге условные. Для всех курсов используется одна и та же подборка книг. Поэтому графики измеряют влияние конвертации. Из этих данных нельзя оценить изменение цен в реальных магазинах. В малых категориях доля заметно меняется от одной карточки.

Условия источников приведены в [правовом чек-листе](legal_checklist.md). Контакт владельца указан в `config.yaml`.
