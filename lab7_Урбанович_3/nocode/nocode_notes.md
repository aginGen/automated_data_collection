# No-code: n8n

`workflow.json` содержит одну схему сбора и обработки ошибок. Учебный каталог books.toscrape.com: три страницы по 20 названий. `Loop Over Items` обрабатывает по одному URL, `Wait` задерживает запрос на 1 с. Проверяются код HTTP 200 и наличие не менее 20 названий на странице. У HTTP Request включён Retry On Fail (до трёх попыток, интервал 1500 мс). Поскольку `neverError` пропускает HTTP-ответы в IF, повторы относятся к транспортным сбоям, а не HTTP 403/404/5xx; Retry-After и повторы 5xx не реализованы.

На ошибочной ветке CSV записывается, затем `Stop with error` завершает выполнение с ошибкой. Для автоматического выполнения срабатывает `Error Trigger` этого же workflow, формирует сообщение и вызывает Telegram. n8n по умолчанию использует содержащий Error Trigger workflow как собственный обработчик ошибки; вручную запускать основной workflow для проверки Error Trigger нельзя. `error_log.csv` перезаписывается, а не накапливается. Ошибка в ином узле может завершить выполнение до записи CSV, но также вызвать Error Trigger при автоматическом запуске. Расписание 08:00 Asia/Yekaterinburg сохранено выключенным.

## Запуск и подключение Telegram

1. Установите n8n 1.121.3 с Node.js 22. Рабочий каталог процесса n8n — папка лабораторной `lab7_Урбанович_3`; перед запуском создайте соседнюю папку `automated_data_collection/.lab-work` и предоставьте процессу право записи. CSV сохраняются в `../.lab-work/lab7_nocode_result.csv` и `../.lab-work/lab7_error_log.csv`, вне папки сдачи. Пути относительны к рабочему каталогу процесса, не к файлу workflow. Импортируйте единственный `workflow.json` в n8n и сохраните.
2. Создайте бота через [BotFather](https://t.me/BotFather) (`/newbot`); для существующего бота выберите `/mybots` → бот → **API Token**. Отправьте `/start` своему боту в личном чате. Не отправляйте токен в чат с ассистентом и не добавляйте его в экспорт.
3. В узле **Send Telegram message** создайте Telegram credential и внесите Access Token непосредственно в n8n; в поле Chat ID замените `REPLACE_WITH_YOUR_CHAT_ID` на ID своего личного чата. ID можно получить из ответа официального метода [getUpdates](https://core.telegram.org/bots/api#getupdates) после сообщения боту; метод не работает, пока у бота настроен webhook. Не публикуйте ответ целиком или URL с токеном. Сохраните workflow. Для Error Trigger, находящегося в том же workflow, отдельная привязка Error Workflow не требуется; не выбирайте другой обработчик в Settings, если нужна эта встроенная ветка.
4. `Manual start` проверяет сбор и не отправляет Telegram. Автоматический запуск по расписанию оставлен выключенным; включайте только при необходимости. Для проверки настоящего уведомления нужен автоматический сбой либо отдельная тестовая схема с настроенным Telegram-узлом и собственным ручным триггером. В этот экспорт она не включена: в проверенной версии n8n редактор допускает один Manual Trigger на workflow.

Для существующей локальной инсталляции настроенный рабочий workflow и Telegram credential сохранены на localhost:15679; не требуется повторно вводить токен для неё. Учётные данные локальной инсталляции и данные бота не включены в экспорт. [Документация Error Trigger](https://docs.n8n.io/integrations/builtin/core-nodes/n8n-nodes-base.errortrigger/), [обработка ошибок](https://docs.n8n.io/flow-logic/error-handling/), [Telegram credentials](https://docs.n8n.io/integrations/builtin/credentials/telegram/).

## Проверки

31.10.2026 единый экспорт импортирован через редактор n8n 1.121.3, ручной запуск собрал 60 строк (SHA-256 CSV `d0dcec641d4ea28ebba3bec1bcb1f9382dd147194a70c728bb7d4c5437f55d21`). На временной копии с локальным webhook вместо расписания и локальным HTTP-получателем вместо Telegram один ответ 403 вызвал запись CSV, Stop with error и собственный Error Trigger; локальный получатель получил одно сообщение с 403. Временный webhook выключен. Снимки `screenshot_self_error.png` и `screenshot_self_handler.png` показывают ошибку и успешное выполнение обработчика этой тестовой копии. Эта проверка не отправляла сообщение в Telegram.

Ранее по явному согласию пользователя отдельная локальная тестовая ветка Telegram отправила ровно одно сообщение; n8n и Telegram-узел сообщили об успехе, ответ содержал message_id. Автоматическую доставку в Telegram при реальном сбое не проверяли. `screenshot_workflow.png` и `screenshot_result.png` — актуальные снимки единой схемы и её успешного сбора; `screenshot_error.png` — предыдущий тест 403 с отдельным обработчиком; `screenshot_notification.png` и `screenshot_telegram_test.png` — предыдущий отдельный обработчик и ручной Telegram-тест. Последние три не являются снимками текущей схемы. Хэш актуального workflow: `fc6ad15b3288de7a39ea126de98402fca4a7797dd7518baebd83ab10b293bf51`. Подробные подтверждения и CSV также сохранены в metadata блокнота анализа.

| Механизм | В коде | В n8n | Ограничение |
|---|---|---|---|
| Скорость | limiter и адаптивная задержка | batch 1 и Wait 1 с | нет общего лимита между процессами |
| Повторы | классификация и backoff | до 3 попыток, 1500 мс | фиксированный интервал для транспортных сбоев, без Retry-After и повторов 5xx |
| Ошибка и проверка | журнал инцидентов и детектор | IF, CSV, Stop and Error, собственный Error Trigger и Telegram | доставка требует настройки credential и Chat ID; CSV не покрывает все узлы |
| Предохранитель | circuit breaker | отсутствует | состояние и half-open не реализованы |
| Условные запросы | ETag/Last-Modified при поддержке источника | отсутствуют | 304 и сохранение валидаторов не реализованы |
| Распределённый лимит | локальный ограничитель | отсутствует | требуется общий координирующий сервис |

Для трёх страниц ежедневно: 1 запуск и 3 HTTP-запроса в день; за условные 30 дней — 30 запусков и 90 запросов без повторов. При транспортных сбоях возможно до 270 попыток за 30 дней при успешном завершении каждой страницы с третьей попытки. Self-hosted Community Edition для учебного внутреннего использования бесплатна; расходы на сервер, электричество и сопровождение оцениваются отдельно. [Условия n8n](https://support.n8n.io/article/can-i-use-your-license-for-my-use-case).
