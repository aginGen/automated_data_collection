# Локальная серия A/B/C: HTML + API

Стенд localhost, не удалённые сайты. До C сохранены 60 HTML-записей с ETag и 100 API-записей с cursor=100; затем API содержит 105 записей. Bootstrap не входит в метрики. Каждая серия возвращает одинаковые 165 записей (60 HTML + 105 API). В C три запроса HTML дали 304, а API вернул 5 изменений с gzip; затем они объединены с сохранёнными 100.

| Запросы | 6 | 6 | 6 |

| Записи | 165 | 165 | 165 |

C передал на 98.53% меньше байтов тела, чем B; B − A = 7.453 с. Все режимы используют одинаковый транспорт с отдельным процессом на запрос; три запроса на каждый домен включают ожидание лимитера. Трафик bootstrap, заголовков и robots здесь не включён.

Отчёты и соответствующие JSONL проверены по числу запросов, кодам и байтам; данные стенда нельзя переносить на удалённые ресурсы.

| Механизм | Запросы до → после | Байты до → после | Экономия |
|---|---:|---:|---:|
| Conditional GET: три страницы books | 3 → 3 | 152720 → 0 | 100.00% |

Для watermark это отдельный управляемый источник изменений, не утверждение об отсутствии изменений на удалённых сайтах. Размер содержимого при 304 в метрике истории берётся из предыдущего кэша; сжатие не считается деградацией.
