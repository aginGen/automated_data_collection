# Правовой чек-лист лабораторной 7

Урбанович И. О., ПМИ-2-2025, вариант 3. Сетевые проверки сохранены 27 октября 2026 года, материалы приведены к структуре ТЗ 31 октября 2026 года.

| Пункт ТЗ | Ответ |
|---|---|
| Источники и их назначение | Books to Scrape — учебный HTML-каталог, Open Library — открытый каталог книг, три JSON-карточки `/works/...json` по ранее сохранённым идентификаторам. Локальный HTTP-стенд воспроизводит отказы и изменения данных. |
| Цель сбора и её правомерность | Учебная проверка устойчивости сборщика на разрешённых в ТЗ источниках. Не собираются тексты книг, изображения, учётные записи или закрытые сведения. Результаты нужны для защиты лабораторной. |
| Условия использования | Books to Scrape прямо называет себя демонстрационным сайтом для обучения сбору данных, цены и оценки вымышлены. Для Open Library проверены документация API, рекомендации по нагрузке и сведения о лицензировании. Условия метаданных не переносятся на тексты и обложки книг. |
| Robots.txt | Результаты проверки сохранены в `analysis.ipynb`, в `metadata.lab7_evidence.reports` под ключами `robots_A.json`, `robots_B.json`, `robots_C.json`. Books: HTTP 404, `can_fetch=True`, Crawl-delay и Request-rate не заданы, Sitemap отсутствует. Open Library: HTTP 200, выбранные `/works/...json` разрешены, Crawl-delay и Request-rate не заданы, Sitemap — `https://openlibrary.org/static/sitemaps/siteindex.xml.gz`. Путь `/search` запрещён, поэтому поиск из лабораторной 3 исключён. |
| Доступ из-под авторизации | При сборе книг авторизация не используется, чужие сеансы и cookies не применяются. HTTP 401 фиксируется без повторов. Токен собственного Telegram-бота хранится отдельно в Credentials локального n8n и не публикуется. |
| Средства обхода защиты | Нет. Один постоянный User-Agent, без прокси, ротации IP, решения капчи и подделки браузерных отпечатков. |
| Объём, частота, пик | Основная локальная серия A/B/C: шесть запросов и 165 одинаковых записей. Сохранённый внешний срез: три страницы Books и три карточки Open Library, 63 записи. В B/C на домен заданы 0,5 запроса/с, burst=1, джиттер до 25% и адаптивная задержка. Новые запуски A разрешены только на localhost. Служебные robots-запросы считаются отдельно. |
| Состав данных и персональные данные | В выходе сохраняются источник, название книги и при наличии идентификатор произведения. Поля авторов, пользователей, биографии и контакты не извлекаются. В этой работе не формируется набор сведений о физических лицах, при расширении полей вопрос персональных данных нужно пересмотреть. |
| Основание обработки при наличии ПДн | К текущему ограниченному набору метаданных отдельная обработка ПДн не заявляется. Публичная доступность API сама по себе не служит согласием на сбор персональных сведений. Поля о людях нельзя добавлять без проверки основания и требований к обработке. |
| Место, срок хранения и удаление | Учебные данные хранятся локально и в GitHub-репозитории автора по его поручению. Срок учебных копий — до проверки и не более 30 дней после неё. Удаление локальных данных включает поля records в reports, снимки metadata.lab7_evidence в блокноте, state, logs и резервные копии. Дата проверки неизвестна, автоматическое удаление не настроено. Код и агрегаты можно оставить. Токены, Chat ID и локальные данные входа n8n в публикацию не включаются. |
| Контакт в User-Agent | `https://github.com/aginGen/automated_data_collection` — публичный репозиторий автора. |
| Претензия или блокировка | При 403 либо заглушке блокировки домен останавливается, сохраняются тело ответа и заголовки, создаётся JSON-инцидент, процесс завершается с ненулевым кодом. Блокировка не обходится. При претензии сбор прекращается, условия и запрос на удаление разбираются до возобновления. При 429 выполняются ожидание Retry-After и снижение скорости. |

Отсутствие robots.txt не даёт разрешения на любую нагрузку. Разрешение `can_fetch` также не заменяет условия использования сайта и оценку состава данных.

Источники: [Books to Scrape](https://books.toscrape.com/), [Open Library API](https://openlibrary.org/developers/api), [лицензирование](https://openlibrary.org/developers/licensing), [использование данных](https://openlibrary.org/help/faq/using), [RFC 9309](https://www.rfc-editor.org/rfc/rfc9309.html).


## Служебные данные Telegram

31 октября 2026 года владелец подключил собственного бота для уведомлений в свой личный чат. Токен хранится в Credentials локального n8n, Chat ID — в параметрах локальной схемы. Владелец сам передал эти данные и отдельно поручил отправить одно тестовое сообщение. Токен и Chat ID не включены в переносимые workflow, набор книг или архив сдачи. Для уведомлений не собираются сведения о читателях, авторах книг или чужих чатах. Удаление локального подключения включает удаление Telegram credential и Chat ID из локальной схемы.
